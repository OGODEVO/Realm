Business rules

1. Gateway is publisher-only

HTTP never runs the model or refund/order logic. It authenticates, validates, and drops a job on the bus.

2. Realm-first routing

Prefer delegate_task(@specialist) → inbox. Domain subjects biz.* later for fan-out/replay.

3. Tools are the only side effects

No ad-hoc prod SQL from the brain. Versioned tools + authZ; escalate when over policy.

4. Dogfood = same OS

Company agents (builder/reviewer) and product apps share one bus. Private configs are a distro, not a fork.

Job contract (stable)
delegate_task → task.progress → task.result | task.blocked | task.failed
Threads = audit/chat. Subjects = delivery. Brains = swappable adapters.
